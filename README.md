## Featured Projects

### IntelliPrint Nexus: Smart Printing Management System

> **Problem:** students need a simple way to submit, pay for and track print jobs, and administrators need visibility into queues, payments and the health of the hardware running the system.

**My role:** Full-Stack Developer & AI/GPU Implementation

- Streamlit + SQLite application with separate student and admin dashboards: PDF upload, print configuration, queue management, simulated payment, QR-based pickup and status-based refund rules.
- Document-quality analysis (OpenCV, TensorFlow/MobileNetV2) and printer recommendation with wait-time estimation, as described in the repository README.
- GPU layer: NVIDIA GPU detection, CUDA-based acceleration with CPU fallback, plus benchmarking, profiling and telemetry scripts; pytest tests and reproducibility documentation.

**Stack:** `Python` · `Streamlit` · `SQLite` · `TensorFlow` · `OpenCV` · `PyTorch` · `CUDA` · `pytest`
**Status:** academic project in active development; runs locally via Streamlit; payments are simulated.

[Repository](https://github.com/sufiiishaikh789-boop/IntelliPrint-Nexus) · [Case study](https://sufiyan-portfolio-pied.vercel.app/projects/intelliprint-nexus) · [Demo](https://lnkd.in/p/gNXJYpDR)

### DineFlow: Restaurant Ordering System

*From Table to Kitchen, Seamlessly.*

> **Problem:** ordering at a restaurant counter or kiosk puts pressure on guests to decide quickly. A screen at every table lets them explore the menu with no queue behind them.

**My role:** developer (per the repository README)

- Table-bound ordering screens (staff PIN or signed table QR link) with menu filters, a "Guide me" wizard, a shortlist and a meal-budget meter.
- Cart, checkout and simulated payment, then a kitchen ticket carrying ticket and table numbers, with live order tracking.
- Staff area: live kitchen board, dashboard, order management (status changes, cancel/refund marking, CSV export), plus menu and table management.
- Security basics documented in the repo: prepared statements, CSRF tokens, escaped output, rate-limited sign-in.

**Stack:** `PHP` · `MySQL` · `HTML` · `CSS` · `JavaScript` · `XAMPP`
**Status:** runs locally on XAMPP; the payment gateway is simulated; not a production deployment.

[Repository](https://github.com/sufiiishaikh789-boop/DineFlow-Restaurant-Ordering-System)
